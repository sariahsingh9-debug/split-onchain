04 / Trust

Clear before
you approve.

SPLIT is designed to show the important payment details before a wallet request is opened.

Payment clarity

Know what you are paying and where it is going.

The participant view surfaces the requested amount, network, asset and creator payout destination before payment. Wallet approval happens through the user’s own wallet interface.

No seed phrase requestsSPLIT should never ask users to enter private keys or recovery phrases.
Visible recipientThe receiving address can be shown before the transaction is submitted.
Network confirmationThe selected network is explicit before the payment flow begins.
Asset confirmationThe selected payment asset is visible before wallet approval.
Creator controlConnect or enter an address

Creators can choose how they provide their payout destination.

Participant controlApprove in your own wallet

The wallet remains the place where the user reviews and approves the transaction.

Shared statusPaid and pending in one view

Payment state stays visible to the group instead of disappearing into chat threads.
