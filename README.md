# SPLIT

Group payments and Solana token launches, hosted on Render.

Use Node 24. Run `npm install`, `npm run build`, and `npm start`. Set server credentials in Render environment variables. See [OPERATIONS.md](OPERATIONS.md) for reconciliation, monitoring, and frontend maintenance.

Token launches currently use Solana devnet. New live group payments require verified persistent storage; until that is configured the form is available for preview. Participant links can be shared manually without invitation email.
